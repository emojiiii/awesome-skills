# Dota 2 Arcade Documentation Source Map

Use this file when deciding where to look first.

## Project Local

- `package.json`: build scripts, template lineage, package manager.
- `src/vscripts`: TypeScript gameplay source.
- `src/panorama`: TypeScript Panorama source.
- `src/common`: shared declarations and contracts.
- `game/scripts/npc`: KV definitions for abilities, items, heroes, and units.
- `content/panorama`: XML/CSS/UI resources.

## Public Sources

- ModDota docs: `https://moddota.com/`
- ModDota article source: `https://github.com/ModDota/moddota.github.io/tree/source/_articles`
- TypeScriptAddonTemplate: `https://github.com/ModDota/TypeScriptAddonTemplate`
- Valve Panorama JavaScript API: `https://developer.valvesoftware.com/wiki/Panorama/Overview/Javascript/API`

## ModDota Article Categories

- `abilities`: ability KV, items, charges, tooltips, server/client examples.
- `abilities/datadriven`: legacy DataDriven examples and targeting details.
- `abilities/lua-modifiers`: modifier tutorial series.
- `assets`: file types, sounds, minimap icons, asset workflows.
- `assets/maps`: Hammer and map-specific workflows.
- `assets/models`: custom models, materials, animations.
- `assets/particles`: particle basics and examples.
- `panorama`: custom UI and Panorama workflows.
- `scripting/Typescript`: TypeScriptAddonTemplate and TypeScript workflow.
- `tools`: Dota 2 custom game tooling.
- `units`: custom unit and hero topics.

## Answer Style

Prefer a short summary with direct links. State whether the source is official Valve documentation, ModDota community documentation, a template convention, or local project evidence.
